# Salgar Case Study: Data Availability

*Geospatial datasets and simulation models for the 2015 Salgar, Antioquia debris flood case study.*

This repository provides geospatial datasets and models supporting the Salgar Case Study paper, which is currently in the publication stage. A preprint is available at:
https://papers.ssrn.com/sol3/papers.cfm?abstract_id=4928955

This case study is part of the author's Master’s thesis, available in full at:
https://repositorio.unal.edu.co/handle/unal/83399

## Data Provided

- Digital Elevation Models (DEMs) and derived products (hillshade)
- Orthophoto imagery
- Watershed boundary shapefiles
- Landslide inventory, runout and debris flood (GeoPackage)

> Rainfall time series are available from the SalgarCase repository: https://github.com/nicolas998/SalgarCase/tree/master

## Model Implementation

Folders under `models/` contain implementation, scripts and results for the following models:

- **Flow-R**
- **IBER**
- **r.avaflow**
